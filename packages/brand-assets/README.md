# Assets de marque OwnMyOwnAI

Fichiers sources dans `apps/web/public/brand/` :

- `icon.svg` — pictogramme seul (favicon, app)
- `logo.svg` — pictogramme + wordmark
- `hero-illustration.svg` — illustration landing

## Régénérer les icônes Tauri

Depuis `apps/runner` :

```bash
npx tauri icon src-tauri/icons/app-icon.svg
```
